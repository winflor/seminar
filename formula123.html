Какие законы используем

  1. Второй закон Ньютона для каждого груза: ma = сумме сил. Он применим, потому что грузы можно считать материальными точками, а система отсчёта, связанная с Землёй, инерциальная.
  2. Третий закон Ньютона: нить действует на блок с той же силой, с какой блок действует на нить.
  3. Нить нерастяжима, поэтому ускорения грузов равны по модулю: a1 = a2 = a.
  4. Нить и блок невесомые, трения нет, поэтому сила натяжения T одинакова по обе стороны блока.
  5. Равноускоренное движение из состояния покоя: h = at2/2. Оно верно, потому что ускорение постоянно (силы не меняются).

Вывод

Ось y направим вниз для груза с перегрузком (масса m + m0) и вверх для второго груза (масса m), то есть по направлению ускорения каждого.

1. Второй закон Ньютона для каждого груза:

(m + m0)a = (m + m0)g − T

ma = T − mg

2. Складываем уравнения (T сокращается):

(2m + m0)a = m0g

a = m0g / (2m + m0)

3. Сила натяжения из второго уравнения, T = m(g + a):

T = m(g + m0g / (2m + m0)) = 2m(m + m0)g / (2m + m0)

4. Сила на ось блока. Блок невесомый, поэтому сумма сил на него равна нулю: F = T + T (нить тянет блок вниз с двух сторон).

F = 2T = 4m(m + m0)g / (2m + m0)

5. Время. Из h = at2/2:

t = √(2h / a)

Проверка с числами

m = 0,5 кг, m0 = 0,1 кг, h = 1 м, g = 9,81 м/с2:

a ≈ 0,892 м/с2, T ≈ 5,351 Н, F ≈ 10,70 Н, t ≈ 1,498 с.

Сравни: если бы перегрузка не было, F = 2mg = 9,81 Н. Значит, при движении сила на ось получилась меньше суммарного веса всех грузов (1,1 · 9,81 ≈ 10,79 Н), потому что система движется с ускорением.
